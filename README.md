# Стабильность локуса маркирования в посессивных конструкциях: сравнение семитских и нилотских языков

Репозиторий содержит расчёты для анализа генеалогической стабильности лингвистического признака **«Локус маркирования в посессивных именных группах» (WALS, параметр 24A)** на материале семитских и нилотских языков. 

В основу расчетов заложена математическая модель из статьи *Wichmann & Holman (2009)*.

## Структура репозитория

* **`possessive.tsv`** — исходные текстовые данные, содержащие выборку из Всемирного атласа языковых структур (WALS). Включают в себя WALS-коды языков, их географические координаты, генеалогическую классификацию (генус, семья) и тип кодирования синтаксической связи (Head marking, Dependent marking, Double marking, No marking, Other).
* **`locus.ipynb`** — интерактивный ноутбук Jupyter на Python, реализующий автоматический подсчет статистических метрик стабильности.
* **`Хитрун_эссе_типология.pdf`** — итоговое академическое эссе, содержащее глубокий лингвистический анализ, историческую справку о диахроническом развитии семитских и нилотских языков, а также методологическую критику количественного подхода и базы данных WALS.

## Описание работы алгоритма

Программный скрипт в файле `locus.ipynb` выполняет следующие шаги:
1.  **Фильтрация данных:** выделяет исследуемые макросемьи — Афразийскую (включающую семитские языки) и Восточносуданскую (включающую нилотские языки).
2.  **Метрика А (Индивидуальная стабильность):** вычисляет вероятность удержания модального (мажоритарного) значения внутри семьи с помощью биномиального распределения, учитывая общее число возможных значений признака ($k = 5$).
3.  **Метрика B (Доля стабильности):** определяет простое отношение частоты мажоритарного значения к общему количеству языков в семье.
4.  **Расчет расстояний (Формула Гаверсинуса):** вычисляет попарные расстояния на сфере (в километрах) между всеми генетически неродственными языками из разных семей.
5.  **Метрика C (Итоговая независимая стабильность):** * Считает средневзвешенное внутриродственное сходство семей ($R$).
    * Находит пары неродственных языков, находящиеся в критическом географическом радиусе **5000 км**, и измеряет долю случайных совпадений признака между ними (базовое ареальное сходство $U$).
    * Вычисляет финальный коэффициент стабильности по формуле: 
        $$S_C = \frac{R - U}{1 - U}$$

## Основные результаты расчетов

По результатам работы скрипта были получены следующие показатели:

* **Афразийская (Семитская) группа ($n=7$):** Метрика A = `0.9667`, Метрика B = `0.5714`
* **Восточносуданская (Нилотская) группа ($n=4$):** Метрика A = `0.8192`, Метрика B = `0.5000`
* **Внутриродственное сходство ($R$):** `0.2442`
* **Ареальное сходство соседей в радиусе 5000 км ($U$):** `0.3077` (выделено 26 пар, из них 8 совпали).
* **ИТОГОВАЯ СТАБИЛЬНОСТЬ ($S_C$):** `-0.0916`

### Краткий вывод исследования
Формальный отрицательный результат метрики $S_C$ говорит о том, что внутри рассматриваемых семей признак статистически менее стабилен, чем среди случайных географических соседей. 

Однако, как подробно показано в прилагаемом эссе, за этой «нестабильностью» скрываются принципиально разные диахронические процессы: фонетическая эрозия падежных показателей в семитских языках и грамматикализация категории отчуждаемости в нилотских. Дополнительным фактором искажения метрик выступает специфика заполнения базы данных WALS, которая фиксирует аналитические конструкции (предложные группы в современном иврите или арабском), игнорируя традиционное вершинное маркирование через сопряженное состояние (*status constructus*).

## Зависимости и запуск

Для запуска расчетного ноутбука вам понадобятся стандартные библиотеки Python для анализа данных.

**Требования:**
* Python 3.x
* pandas
* numpy
* scipy

**Запуск:**
1. Склонируйте репозиторий.
2. Установите зависимости (если они не установлены): `pip install pandas numpy scipy notebook`
3. Запустите сервер Jupyter: `jupyter notebook`
4. Откройте и выполните ячейки в файле `locus.ipynb`.
